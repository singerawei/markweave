## 自动验证与实测

`npm run check` 包含 lint、类型检查、64 项核心/往返/评估/门禁回归与生产构建。`npm run test:ui` 的 14 项界面测试通过，包括 26 个代码样例、3 万搜索命中、重复引用合并撤销，以及 320/400/600/900/1280 px 下 100%/200% 布局。

真实宿主与安装包证据以 [新版原始记录](review-artifacts/response-0.3/) 为准。打开计时不含 VS Code 应用启动；CDP 合成键盘双帧延迟不等于物理键盘或真实中文 IME 延迟。PDF 已检查中文、未保存 Include、Mermaid、页眉页脚代表页，不能据此声明 30 份视觉矩阵完成。

最终安装包的功能宿主检查正常退出。[完整实测与门禁结果](review-artifacts/response-0.3/RESULTS.md) 对应安装包及实际运行文件哈希，最终单轮采样如下：

- 20 张 Mermaid 冷态全部完成为 3.592 秒（原报告约 17 秒）；缓存重开全部完成为 366 ms。冷态首图为 2.243 秒，仍超过 1.5 秒目标。
- 5 MB 首屏可编辑为 1393 ms，合成输入 P95 为 47.1 ms；100 KB 代码合成输入 P95 为 46.5 ms。各场景只有 100 次输入，不能代替 1000 次验收。
- 搜索三种查询为 179–283 ms，最多 43 个结果按钮；功能切换、Esc、本地撤销及非法 PDF 参数取消检查通过。
- 短时滚动测试最慢场景帧间隔 P95 为 74 ms，仍需改进，且不能代替 60 秒验收。OS 剪贴板读回为 0/20，已明确保留失败状态。

## 尚未满足的稳定发布条件

真实中文 IME 每种至少 1000 次提交、10 人可用性研究、30 份 PDF 视觉矩阵、50 次故障恢复与长时间稳定性仍需验收。打开 30 轮、每类输入 1000 次、60 秒滚动、50 次定向保存等若样本不足，必须保留未通过状态。剪贴板当前环境无法确认，不计为成功。

`npm run release:gate` 读取 `review-artifacts/response-0.3/acceptance.json`，缺证据或超过门槛就阻止稳定发布；开发包生成不代表门禁通过。测试使用隔离配置、扩展目录和临时语料，不改用户日常 VS Code 配置。
