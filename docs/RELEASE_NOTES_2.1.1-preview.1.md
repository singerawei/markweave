# MarkWeave 2.1.1 (Preview 1)

A polish release for the 2.1 line. Windows x64, VS Code 1.100+.

## Highlights

- **Reading typography** — clearer H1–H6 scale and spacing, full-width layout, calmer links and quotes.
- **Tables and code** — bordered tables with zebra rows and hover states; quieter code blocks with clearer syntax colors.
- **Dark theme** — palette verified by an automated readability test.
- **Documentation** — English-first README with a hero screenshot, plus 简体中文, 日本語, 한국어, Español, Français, Deutsch and Русский editions.

## Install

1. Download `markweave-win32-x64-2.1.1.vsix`.
2. In VS Code, open **Extensions → … → Install from VSIX…** and select the file.
3. Reload VS Code, then right-click a `.md` file and choose **Open With… → Modular Markdown Editor**.

No separate Chrome or Edge installation is required.
